# Astra Studio Landing Page

A premium corporate-style landing page built with semantic HTML5, CSS3, and vanilla JavaScript.

## Structure

- index.html — main page structure and content
- css/style.css — all styling, layout, animations and responsive behavior
- js/main.js — scroll effects, menu toggle, reveal animations, count-up stats, and testimonial slider

## Run locally

Open the project in a browser directly, or serve it with a local static server:

```bash
cd c:/Users/digital-vision.ir/Desktop/coding
python -m http.server 8000
```

Then visit http://localhost:8000

## Notes

- Fully responsive across desktop, tablet and mobile
- Includes premium dark UI, glassmorphism, hover effects and subtle motion
- Accessibility-friendly with keyboard focus states and reduced motion support
- Placeholder images are pulled from Unsplash and can be replaced with project-specific assets
